# 造梦西游1 · PyGame 复刻版

一个基于经典页游《造梦西游1》的个人单机复刻项目。用 PyGame 重新实现了原版的
主线流程、双主角、技能、装备与界面，离线运行，无需联网、无需账号，也没有任何
充值、广告或活动入口。

本项目是非官方粉丝作品，与权利方无关联；源代码以 MIT License 开源，详见文末
「开源协议」。

## 内容特色

- **双主角**：孙悟空、唐僧，各自拥有独立的普通攻击与技能体系。
- **主线关卡**：1-1 至 3-3，4-1 牛魔王三阶段连战，以及从 1-2 副本门进入的
  9-1 水晶宫。
- **原版风格表现**：封面、选角、选关地图、加载动画、战斗 HUD、Boss 血条、
  连击与伤害数字均按原版重绘。
- **角色养成**：装备、背包、技能商店、属性面板与升级。
- **完整流程**：开场字幕、关卡战斗、死亡失败、通关与结局。
- **三槽存档**：自动保存与手动保存，随时继续上次进度。
- **操作方式**：键盘 + 鼠标，支持窗口与全屏。

## 运行环境

- Windows 10 / 11
- Python 3.12 或更高版本
- pygame-ce（版本见 `requirements.txt`）
- pyinstaller（版本见 `requirements.txt`）
- 已解压的 `assets/` 素材目录（见下文「素材说明」）

## 快速开始

### 方式一：从源码运行（需要 Python）

1. **安装 Python**：到 [python.org](https://www.python.org/downloads/) 下载并安装
   Python 3.12 或更高版本。安装时务必勾选 **Add python.exe to PATH**。
2. **安装依赖**：打开 PowerShell 或命令提示符，执行：

   ```powershell
   python -m pip install pygame-ce pyinstaller
   ```

   `pygame-ce` 用于运行游戏，`pyinstaller` 供 `build.bat` 打包使用；也可以直接
   执行 `python -m pip install -r requirements.txt`。
   如果 `python` 命令不可用，请改用：

   ```powershell
   py -3 -m pip install pygame-ce pyinstaller
   ```

3. **准备素材**：把素材包解压到项目根目录，确保 `assets/` 与 `main.py` 同级
   （见下文「素材说明」）。
4. **启动游戏**：双击 `run.bat`；或在项目目录执行：

   ```powershell
   python main.py
   ```

> 双击 `run.bat` 后提示找不到 Python，通常是安装时没有勾选
> **Add python.exe to PATH**；重新运行安装程序并勾选该项即可。

### 方式二：下载打包版（无需 Python）

到项目的 Release / 发布页面下载最新的 `zmxy1_pygame_v*.zip`，解压后进入
`zmxy1_pygame` 文件夹，双击 `zmxy1_pygame.exe` 即可游玩。打包版已包含
`assets/` 与 `data/`，请保持它们和 exe 在同一目录，不要只把 exe 单独拷走。

游戏内按 `F11` 可切换全屏。

## 素材说明

本仓库只包含程序与数据，**不包含 `assets/` 目录**。该目录存放原版美术、字体与音频，
体积较大且版权归原权利方所有，因此不随代码一起分发，已在 `.gitignore` 中排除。

运行游戏前，请将素材包单独下载并解压到本项目根目录，使结构如下：

```
assets/
├── manifest.json
├── audio/
├── sprites/
└── ...
```

缺少 `assets/` 时游戏无法启动。

## 操作说明

按键以游戏内「帮助」面板为准，通用操作如下：

| 操作                | 按键               |
| ------------------- | ------------------ |
| 左右移动            | `A` / `D`          |
| 奔跑                | 双击并按住方向键   |
| 普通攻击            | `J`                |
| 跳跃 / 二段跳       | `K` / 连按两次 `K` |
| 从单向平台向下穿过  | `S` + `K`          |
| 进入传送门 / 副本门 | `W`                |
| 无双（气满时）      | `Space`            |
| 打开背包            | `C`                |
| 技能商店            | `V`                |
| 暂停 / 设置         | `Esc`              |
| 全屏切换            | `F11`              |

两个角色的技能按键不同：

**孙悟空**

| 技能     | 按键         |
| -------- | ------------ |
| 升龙斩   | `↑` + `J`    |
| 火炎突击 | 奔跑中按 `J` |
| 烈焰闪   | `U`          |
| 烈焰风暴 | `I`          |
| 火魔斩   | `O`          |

**唐僧**

| 技能     | 按键          |
| -------- | ------------- |
| 冰龙波   | 长按 `J` 蓄力 |
| 玄冰阵   | `U`           |
| 水幻影   | `I`           |
| 天降甘露 | `O`           |
| 水魔爆   | `L`           |

具体效果与解锁条件以游戏内技能商店和提示为准。

## 存档说明

- 存档保存在 `saves/` 目录下，共三个槽位：槽 1 唐僧、槽 2 孙悟空、
  槽 3 双人（双人战役暂未开放）。
- 击杀怪物、通关关卡时会自动保存；选关地图上的「保存游戏」可手动保存，
  有 30 秒冷却时间。
- 想重新开始，删除或重命名 `saves/` 下的对应存档文件即可。
- 存档属于本地个人数据，不会上传到任何地方。

## 已知限制

- 双人战役尚未开放，选择双人后会提示并返回封面。
- 竞技场需要双人模式，当前不可进入。
- 作为个人复刻作品，部分动作、数值与细节仍与原版存在差异。
